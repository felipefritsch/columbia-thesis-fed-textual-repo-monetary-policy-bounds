# Data

`data/raw/` is read-only input. Everything in `data/processed/` is regenerated by `make data` / `make results`.

| File | Contents | Source |
|---|---|---|
| `akj_outcomes.csv` | Monthly fed funds rate, PCE price index, industrial production index, unemployment rate, Aug 1989 – Dec 2010 | Replication files of Angrist, Jordà & Kuersteiner (2018, *JBES*), file `realvaroriginal.csv` |
| `akj_pscore_vars.xls` | Monthly target change, fed funds futures surprise (`DEAJKold`), lagged PCE inflation and Δunemployment, meeting and month dummies | AJK (2018) replication files. The copy here also carries the 2020 hand-pasted menu dummies (`d_menu_*`); the revised pipeline ignores them and rebuilds menus from `bluebook_policy_menus.csv` (they agree month by month) |
| `bluebook_policy_menus.csv` | For each FOMC meeting 1988–2008: which alternatives (ease / unchanged / tighten, and in 25 bp steps) the Bluebook offered | Extracted from the Bluebooks by regular expression + manual classification (thesis §2), built on the FOMCTextAnalysis project of Montiel Olea, Giesecke, Chitale & Frermann: https://github.com/jm4474/FOMCTextAnalysis. Last three rows are malformed in the source and are dropped on load |
| `fomc_text_panel.csv` | Monthly macro panel Jan 1920 – Aug 2019 (IP growth, PCE, target, menus...) | FOMCTextAnalysis project. Dates are stored as m/d/yy; rows are consecutive months from Jan 1920 |
| `greenbook_forecasts.csv` | Staff Greenbook projections by Greenbook date and forecast quarter | Philadelphia Fed Greenbook data set (column `meeting_date` is the Greenbook date) |

Not included (were in the old folder, not used): FRED downloads `PCEPI.xls` / `INDPRO.xls` (superseded by `fomc_text_panel.csv`), stale duplicates of `data_replication.dta`.
